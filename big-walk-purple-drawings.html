36 Drawings

A visual matching puzzle. Pair up 36 drawing boards, many of which look nearly identical. The key is asking for detail instead of assuming.

Before you start

  • Reached Challenge Ridge
  • At least 2 players, both able to see the boards

How to solve it

  1. 01

    Spread out the boards

    Pull all 36 boards off the rack and spread them so both players can see them.

  2. 02

    Ask for detail

    Don't just say 'looks the same' — ask 'filled or outline?' and 'how many petals?'.

  3. 03

    Split into two piles

    Put confident matches in a 'sure' pile and the rest in a 'maybe' pile.

  4. 04

    Match

    Pair up the drawings by description.

  5. 05

    Re-check on failure

    If you get it wrong, re-check the 'maybe' pile first.

Mechanics · Detail · Roles · Speed up

The core mechanic

Pull all 36 boards off the rack and spread them where both players can see, then the game gives you a target and you find the one drawing that matches. It's a 'compare and find the difference' visual puzzle.

Avoiding mistakes via detail

Many of the 36 look nearly identical; the differences are in the details — filled or outline, how many petals, which way it faces. Ask about those before you decide, rather than trusting the rough outline.

Roles

One player looks and describes the target's features, the other scans board by board to match. Pull a candidate out and confirm it with your teammate before committing, rather than instantly rejecting settled ones.

Speed it up

Split into a 'sure' pile and a 'maybe' pile — lock the sure ones immediately, and only re-check the maybe pile at the end. If you get one wrong, go back to the maybe pile rather than re-doing everything. Keep visually similar boards separated when you spread them.

Why it won't work

Keep matching wrong?

Roughly group the boards by color / shape / count first, then refine within each group.
